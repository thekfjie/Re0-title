# 参考截图的像素测量与视觉校对

本分析读取了全部 82 张原始 JPG，逐张查看七张原始联系表，并对难样本查看更大预览；随后逐张查看七张保留墨迹 QA 联系表。所有原图都是 3200×1440。测量只针对主体日文标题；两个纯拉丁标题也保留记录，但不纳入黑底日文统计。

## 产物及复现

- `measure_references.py`：Pillow、NumPy、SciPy 实现，无 OCR、LLM、VLM 或 embedding。
- `measurements_config.json`：82 条经过视觉校准的裁剪、遮罩、阈值、置信度配置。
- `measurements.json`：逐样本 bounding box、留白、视觉中心、近似颜色簇及强调色位置、connected components、完整行像素投影。
- `measurements_summary.json`：总体统计、59 条可靠黑底日文记录的分布及分层统计。
- `measurement-qa/1.jpg` 至 `7.jpg`：只显示测量保留像素，供查看 UI、翻译或背景是否误入。

从仓库根目录运行：

```bash
python3 analysis/measure_references.py
# 显式使用已经校准的配置
python3 analysis/measure_references.py --config analysis/measurements_config.json
```

固定算法与 RGB 量化合并流程没有随机性。不同版本的 JPEG 解码器仍可能造成边缘像素差异。配置按文件名排序绑定此批 82 个文件，不能直接套用到新增截图；脚本会拒绝样本数量不同的输入。

## 画布与翻译剥离

原视频画布为原图坐标 `[448,72,2752,1368]`，即 2304×1296、16:9。bounding box 使用半开区间 `[left,top,right,bottom]`，均为原图像素。

每张图片有独立的 title clip。左上 bilibili 水印和左下观看人数位于裁剪范围以外；中文翻译并非统一在下方：样本 17 在左侧、21 与第一行共享纵向范围、37 与 46 等在顶部、80 直接嵌入主体字符之间。因此不能只套一个下边界或按最后一行统一剥离。样本 17、21、69、80 增加人工校准的排除矩形。69 的上方中文与两个小遮挡方块已从主体裁剪中排除。

底色分类有 73 个黑色基底/黑色为主画布、9 个白底画布。前者包含少数光照、雪花、血迹或彩色纹理，不代表 73 张都是纯黑背景。9 个白底样本索引为 25、29、31、60、65、69、70、77、82。

## 各字段的含义

`title_ink_bbox` 是裁剪、对比度阈值、局部背景过滤和小连通块清理后的可见墨迹范围。常规黑底使用 `max(R,G,B)>35`；白底使用距白色的对比度；特殊背景使用灰度/亮度/强颜色过滤。阈值和过滤方法都保存在样本配置中。小连通块阈值为 20 像素。

`canvas_whitespace_ratio = 1 - ink_pixels / canvas_area`，`bbox_whitespace_ratio = 1 - ink_pixels / bbox_area`。前者把标题以外的全部画布视为留白，后者包括字内空腔、字符间隙、行间空隙。这两个字段不是同一个概念，bbox 面积也不能替代 ink 面积。

二值墨迹中心为所有保留像素的算术平均；对比度加权中心按像素距背景的亮度对比加权。后者是视觉重心的简易代理，未包含人类对颜色、语义或高频纹理的完整感知。归一化坐标相对于视频画布，中心点是 `(0.5,0.5)`。

颜色测量先腐蚀二值 mask 两个像素，以减少 JPEG 和抗锯齿边缘；再做 24 级 RGB 量化与距离小于 60 的确定性加权合并。至少占核心像素 2% 的簇标为 significant；RGB 通道跨度大于 35 的簇标为 chromatic。强调色位置使用邻近颜色中心且有色度的核心像素，另提供 1%–99% 位置分位范围以抑制离群点。RGB 中心、占比和位置都是近似测量，不是设计师实际用了几种颜料的真值；渐变、投影及 JPEG 压缩会增加簇数。

`connected_components` 是八连通墨迹块。一个字符可能有很多不相连的笔画，两个字符也可能直接连接，故不能将这些块当作 glyph、字符或 token。它们只适用于查看局部墨迹分布和碰撞候选。原图的真实字号、advance、bearing、字体名称、字重、字符横向缩放，不能从这些块反推为精确值。

`row_projection` 保存裁剪区域每一个 y 的墨迹像素数。`ink_bands` 为平滑、阈值与窄间隙合并后的投影带，不是自动识别的文本行；错位排版会使两行接触或合并。`manual_visual_line_count` 另由视觉标注提供，描述主体标题的可读行数。该标注不包括中文翻译或反射副本。

未运行 OCR，`automatic_text` 和 `glyph_metrics` 为 null；本文件不声称得到了逐词字号、原始文本、准确字距或字体混排鉴定。相关文字信息应由独立人工转写与 tokenizer 处理，字体身份及非均匀缩放仍属于待验证假设。

## 统计观察与排版含义

可靠黑底日文子集有 59 条，其中 37 条单行、20 条双行、1 条三行、1 条四行。总体 bbox 宽度占画布中位数 0.699，高度占比 0.386，宽高比中位数 3.201。单行的 bbox 宽高比中位数 3.958，双行中位数 2.406。短、宽、堆叠形态不能由一条固定换行规则替代。

这个子集的墨迹画布留白中位数为 0.897，bbox 内留白中位数为 0.615；bbox 画布面积占比中位数为 0.282。标题可以横向很宽，同时只占约一成实际画布像素。优化器宜分别约束安全边界、墨迹面积与块内疏密，不能只奖励“把文字铺满画布”。

对比度加权中心归一化中位数约 `(0.483,0.509)`，四分位 x 范围 0.468–0.502、y 范围 0.497–0.514。全体主要围绕画布中心，但不是强制每行的几何中心一致；灰色大字会在二值中心和加权中心之间产生差异。块的错位应以整体墨迹重心评价。

59 条中有 37 条近似 1 个显著有色簇、2 条有 2 个、1 条有 4 个，19 条没有显著有色簇。没有有色簇不代表没有强调：灰色、字号或字形仍可能承担层级。全标题随机多色处理缺乏此批主体样本的统计支持；一个局部强调色是常见状态，多色应作为独立候选。

按文件排序，前 24 条均属于可靠黑底子集：bbox 宽度中位占比 0.855，高度 0.455，墨迹留白 0.848；后 35 条可靠黑底的相同指标为 0.656、0.315、0.916。样本存在明显尺度区段。这里不解释其制作年代或版本来源，但提示不要把所有图片平均成唯一的字号目标。候选可以保留“更满的标题尺度”与“更克制的标题尺度”；模板/布局家族仍需结合文本和视觉关系标注。

## 低置信度与排除

普通测量 high 65 条，medium 5 条，low 11 条，excluded 1 条。high 只表示标题像素相对容易分离，不等于推断的字体身份或单字尺度准确。

主要特殊情况如下：

| 索引 | 状态 | 测量处理与局限 |
| --- | --- | --- |
| 26 | low，拉丁/发光 | 较高亮度阈值仍可能包含部分发光；不用于日文统计 |
| 27 | low，雪花 | 中央裁剪避开装饰；无法证明保留像素全属于文字 |
| 31 | medium，白底花瓣 | 暗字过滤压掉淡花瓣；可能丢失淡边缘 |
| 36 | low，灰色渐变、字幕靠近 descender | 颜色/亮度过滤尽量去掉字幕；底部像素边界仍不确定 |
| 41 | high，纯拉丁 | 像素分离可靠，但不用于日文统计 |
| 43 | low，紫色背景光 | 提取中性色；字与光照的准确边界未知 |
| 50 | low，镜面反射 | 测量主体、抑制反射；镜面边界近似 |
| 53 | low，黄色背景光 | 强颜色/中性色过滤；不可用于精确墨迹面积统计 |
| 54 | medium，血迹背景 | 抑制红色背景，测量灰/白标题；红色不能计作标题强调色 |
| 58 | low，暗字纹理 | 阈值影响字形纹理和墨迹面积 |
| 62 | low，彩色扭曲背景 | 只测近白标题核心，丢失抗锯齿边缘 |
| 64、75 | low，发光/附着星形 | 可见效果混入墨迹，不能当作字体轮廓 |
| 65 | medium，极淡白底字 | 较低对比阈值，易受 JPEG 小噪点影响 |
| 69 | excluded，遮挡 | 只保留可见标题和遮挡块，不推断被遮的字，禁止纳入风格统计 |
| 70 | medium，淡水纹背景 | 暗字过滤可能丢失部分纹理笔画 |
| 80 | low，翻译嵌入 | 人工矩形去翻译，可能同时裁掉下方字的少量边缘 |
| 81 | medium，破碎/旋转字 | 可见碎片是标题效果，无法由 mask 精确恢复 glyph 轮廓 |

所有白底、纯拉丁和上述特殊黑底记录均从 primary_black 子集剔除，原始记录仍完整保留。统计没有经过 OCR、字形级校正或大模型推断。它们足以验证画布密度、总体重心、颜色数量和宽高形态；不应拿来宣称精确恢复了参考字体或设计师的所有操作。

## 六张逐字/假名组细标

追加的 `fine_annotations.json` 为 s002、s006、s014、s030、s035、s048 共 36 个单元记录原图墨迹 bbox、核心观测 RGB、视觉角色、行号、相对于本图汉字墨迹高度中位数的比例。六张原图与六张 bbox 叠加预览均分别用 view_image 检查；预览位于 `fine-annotation-qa/`。`fine_annotate_references.py` 可重建细标文件。

本批恢复的主体原文来自人工目视转写，而非 OCR。多数 bbox 由正确归属笔画的 component 合并；s002「再/会」、s006「の/音」、s035「価/値」笔画相接，使用人工校正边界并标 ±12 原图像素/边；s048「壊/の」由视觉及色差分离，标 ±6 像素/边；普通 component 合并采用 ±3 像素/边的保守误差估计。这些不是统计置信区间。

字号、字体 family 均为 null。所有“大小”字段严格描述墨迹 bbox 高度，不代表 font-size；字形固有形状、分离笔画、基线、裁切及缩放都能改变 ink 高度。s014「う」的顶部独立笔画必须并入；其较高 ink bbox 不能据此断言字号更大。s030 将「ちかねた」四字合组，避免把相连笔画猜成精确逐字 bbox；该图的汉字/假名比以假名组高度作分母，不能与逐字中位数直接混合拟合。

s048 含标点的最大/最小 ink 高度比为 6.114；这个值主要反映小标点，不应当作正文字符的缩放范围。s035 以红色「の」强调连接字符；s048 的第一处「り」和第二处「ま」为粉色，说明本组参考的强调色也可能落在假名。六张是有意挑选的细标样本，不能据此估算全体标题的字号分布或假名强调频率。
