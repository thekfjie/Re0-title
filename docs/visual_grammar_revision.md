# 从字之间的关系学习风格

2026-10-11。剧情和角色可以提供额外的创作语境，但不应成为生成这种风格的前提。上一轮研究对叙事解释赋予了过多权重。这一轮回到原图可直接观察的构图关系。

## 本轮认识

参考的自由感来自局部关系：大字为小字提供依托，小假名进入大字之间的空间，某个色点改变阅读停顿，相邻行的轮廓互相呼应。基线、字号和行宽可以变化，文字仍有稳定的阅读顺序和整体重心。简单的等宽模板、统一下移、随机抖动都不能代替这些关系。

| 关系 | 原图证据 | 对生成器的含义 |
|---|---|---|
| 词义重要、字形大、带颜色分别决定 | 035「命」大，「の」小且红；051「血／臓物」暗灰，白色「愛」承担主视觉 | 不让一个 importance 同时控制大小和颜色；白色也能是主角 |
| 以字为单位组织词的轮廓 | 002「魔」明显高于同句其他汉字；005「約束」只在「束」上设色点 | 保留词的语义边界，但允许词内不同字承担不同视觉职责 |
| 假名形成有变化的连接带 | 014「と」「い」「う」的大小和上下位置不同；030「ちかねた」嵌在「待」与「再」之间 | 小假名依附邻近锚点，不能统一缩小后排到一条基线上 |
| 出现位置比全局字符标签更关键 | 048 两次「始まり」分别着色「り」「ま」；024 两个「騎」不同颜色 | 每一次出现分别判断，不能搜索替换所有同字 |
| 错位按块的轮廓组织 | 048 四行形成两组前后错位关系；080 两部分大幅错开 | 用组之间的依附、空隙和重心评价布局，少依赖固定阶梯 offset |
| 色点往往局部而稀疏 | 更新的色位复查有 98 个记录单元，其中 79 个为单字符；其中包含灰色弱化与整幅效果 | 不把所有“不同于基色”都当强调，不要求每张必须有亮色 |

六张细标测量中，002「魔」的 ink 高度为汉字中位高度的 1.49 倍；035「命」为 1.43 倍，「の」为 0.58 倍；014 的「と／い／う」分别约为 0.60／0.50／0.81 倍。它们是实际可见字面高度，有人工边缘误差，不是字体字号真值。字体身份仍未知。

这意味着可复用的规则应该描述“谁依托谁、哪块形成停顿、哪里留一个空隙”。规则本身可以严谨，输出不需要呈现整齐网格。

## 独立构图实验

在共用 Python 字体、HarfBuzz shaping、轮廓 Renderer 和硬约束之后，加入一个可关闭的构图阶段：

1. 每行区分主锚点、次锚点、主体字、浮动假名、连接字和标点；按 ink 高度形成层级。
2. 根据新字形大小和位置重新测量视觉字距，保持原文顺序。
3. 相邻行尝试进入对方空白轮廓，实际 ink 接触检查限制向上嵌入量。
4. 在几何形成后选择色点，实验白色大字旁的小色点、短标题中唯一「の」的连接色点、双锚点。importance 只作为较弱依据。
5. 保留每个出现位置的手动颜色；重复助词不自动一起着色，`none` 模式不自动着色。

发现并修正一个字形问题：直接把「ー」的薄墨迹高度放到汉字高度会产生巨大横条；长条字形按宽度尺度处理并保留自身比例。这一修正仅属于实验阶段。

实验参数在 `config/template_rules.yaml` 的 `composition` 下；`enabled: false` 是正式服务默认值。Python 的 A/B 都可通过同一 `LayoutEngine` 使用该阶段；本轮实际重跑的是 A 的构图消融，没有新调用模型，也没有新的 B 胜率结论。浏览器正式生成仍使用现版引擎，网站的“构图实验”页展示这轮冻结结果。

## 全量结果与采用决定

82 个参考标题加 4 条新文本，两版各保留六候选，共 1,032 张结果。两版使用相同 Noto Sans JP Black + Shippori Mincho SemiBold 字节、seed=42、文本、画布和基础评分。生成不读取剧情、原图、参考断点、色位或标题 ID。对照统计在生成之后才读取人工标注。

| 默认候选指标 | 现版 | 构图实验 |
|---|---:|---:|
| 行数一致（81 条） | 57 | 59 |
| 断行完全一致（81 条） | 56 | 58 |
| 色位平均 Jaccard | 32.67% | 25.16% |
| 形状比例绝对 log 误差中位数（59 条，越小越好） | 0.2174 | 0.1905 |
| 字面高度比例平均绝对 log 误差（6 条） | 0.1983 | 0.1942 |
| 文本完整性失败 / 溢出 / 禁则违规 | 0 / 0 / 0 | 0 / 0 / 0 |
| 最大低分辨率 ink 重叠率 | 0.002972 | 0.002937 |
| 引擎延迟中位数 | 717 ms | 762 ms |

色位评价使用更新的 98 单元复查：修正 036 的第二个重复片段位置，补入 031「親」和 035「命」的灰色单元；两版都用这套标注重算。旧“82 张参考对照”页面保留冻结的 96 单元数据及 31.45% 结果，两处差异来自标注版本，现版生成图相同。色位标注包含灰色层级，并非只统计亮色；遮挡转写 069 不进入内容对照。新文本只检查生成、完整性和约束，没有原图匹配目标。延迟不含字体加载、PNG 转换和网络。此批参考参与开发，没有独立盲评，指标不等于审美评价。

**本轮不采用实验作为默认。** 形状比例有小幅改善，但色位重合下降，六张细标的高度变化也很有限。逐页查看全部 82 张对照后，仍见这些问题：002、014 默认把色点和最大字压在开头；033 的小「の」经常没成为连接色点；048 的默认仍可能选择两行；片假名名字中的中点过大；白色主视觉与灰色弱化仍未学到。统一的“主锚点高度／主体高度”也产生了另一种重复模式。

这些结果进一步说明：扩大字号差异、增加错位本身不足以形成参考风格。后续重点应是局部字对和字组之间的构图关系，以及候选评分能否识别这些关系；不能靠多加几个固定模板或引入剧情要求来补偿。

## 复现与查看

```bash
.venv/bin/python -m experiments.composition_study --all
.venv/bin/python -m pytest -q
npm test
```

`experiments/composition-study/results.json` 保存字体 hash、完整配置、两版参数、各字形坐标、实际色位、分数项与全部候选。`index.json` 供网页加载；`contact-1.jpg` 到 `contact-11.jpg` 展示原图、现版默认、实验默认和第二候选。第二候选按生成器顺序展示，不按原图挑选。

网页 `/composition-study.html` 可搜索全部 86 条文本、分别切换两版六候选、放大并下载 PNG/SVG。与生成器的 A/B 对照页分别保留，避免把本轮 A 的构图实验误称成新的 A/B 模型对比。
