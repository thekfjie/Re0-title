# 使用说明

## 生成标题

1. 输入日文标题，或从“参考标题 · 82”中选择一句。
2. 选择 A 或 B，分别设置汉字和假名字体。
3. 点击“生成”，查看候选；点击缩略图切换大图。
4. 按需要改色，再下载 PNG、SVG 或参数 JSON。

默认生成 6 张，也可以选择 4 张或 8 张。候选的区别包括构图、断行和字号关系，第一张不一定最适合你的用途。

## 字体

可以直接使用预置的 8 款开放字体。汉字选粗 Gothic、假名选 Mincho 是一种可尝试的组合；同一字体用于两者也可以。

上传自己的 `.ttf` 或 `.otf` 后，在相应的字体位置选择它。字体缺字时，界面会提示具体字符。Python 上传接口的单文件上限为 24 MiB，单会话最多 8 个文件、合计 64 MiB。上传和私有字体不会获得公共下载链接。

浏览器版与 Python 上传 API 的字体保存方式不同，见[字体管理](font_security.md)。

## A、B 和中文输入

A 用分词和规则确定重点，不调用大模型。B 先请求模型分析标题，再使用与 A 相同的排版和渲染流程。B 需要服务端配置模型；配置缺失或请求失败会显示错误。

中文输入有两种处理方式：

| 方式 | 处理内容 | 模型调用 |
| --- | --- | --- |
| 自动转为日文汉字 | 转换字形，保留原句语法 | 无 |
| 中文标题 → 日语 | 翻译整句，可检查、编辑译文 | 有 |

字形转换不会把中文语法变成日语。整句翻译后仍可选择 A 排版，界面会标记为“中文翻译 + A”。

## 配色和局部改色

预设有蓝 / 粉、紫 / 黄、红 / 灰、灰 / 白。“自动强调”决定强调数量；“单色强调”和“双色强调”指定数量方向；“统一前景色”取消自动强调。

在“自定义配色”里启用自定义颜色，可设置前景色并添加最多 8 种强调色。自动色过于接近背景时会经过可读性检查；局部手动色会保留，并在低对比度时提示。这项检查不代表原作的设计意图。

生成后，在“局部颜色”中选中要修改的字，设置颜色并应用。Shift 连选，Ctrl / Command 多选。同一句里两个“の”或“的”按各自位置处理，可以只改其中一个。局部改色同步到本组候选；“恢复自动”撤销所选位置的覆盖，“恢复全部自动色”清除全部覆盖。

自动着色按文字规则和语义计划选择位置，不知道角色代表色或剧情含义。对位置有明确想法时，直接使用局部颜色。

## 画布、明暗和透明背景

右上角 Day / Night 改变界面。“画布与复现”里的黑底 / 白底改变输出画面，两者独立。

画布宽高可分别设为 256 至 2400 像素，总面积不超过 400 万像素。下载区勾选“透明背景”，PNG 会包含透明通道，SVG 会去掉背景矩形。透明选项和局部改色立即作用于导出，无需重新规划。

PNG 适合直接使用；SVG 以字形轮廓保存，适合缩放或继续编辑，不依赖系统字体。请自行保留字体使用授权。

## “换一组”和 Seed

“换一组”改变 Seed，让字号、错位、留白和候选发生变化。Seed 是这组随机变化的编号。同一运行端、字体、文本、语义计划和配置下，使用同一 Seed 可以复现布局。

它不控制模型每次返回的内容。B 的计划会暂存在当前页面内存；修改字体、配色、画布或 Seed 时复用计划，“重新规划”才再次请求模型。需要保存 B 的完整结果时，同时保存参数 JSON。

浏览器和 Python 的分词、随机数与栅格实现不同，同一个 Seed 不保证两端生成相同图片。
