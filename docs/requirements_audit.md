本轮通过六张细标重新校正假名 ink 高度、连续汉字比例、错位基线、局部压缩、助词强调和成对短句的四行结构。参考强调位置只启发规则，不用图片身份去检索一张现成成品。字体改变不能替代布局验证。

这六张细标已用于规则修正，因此属于开发样本。原先排除 Benchmark ID 的面积拟合仍可复现，但本轮风格迭代不再把这些样本称为严格未见测试。七条新增输入仅检验生成与约束；尚未证明未知文本的审美泛化。

追加：中文字形转换（不调用模型）与整句翻译（显式模型预处理）均已接入；界面 Day/Night 与导出画布独立；Seed/颜色修正及客观审计见 `input_seed_color.md`。中文原文不冒充日文语法，译文与完整 plan 在导出参数中记录。

颜色续修：82 张逐样本色位复查、自定义 1–8 色池、按具体字符位置覆盖、恢复自动色，以及即时透明 PNG/SVG 已实现。颜色和编辑规则在 A/B 间共用；短标题桥接与语义重要度分开。当前限制见 `color_rules_revision.md`。
