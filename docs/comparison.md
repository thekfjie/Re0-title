# A / B 实时对照

20 条标题（13 条参考文本、7 条新增输入），每方案 6 张，合计 240 张。相同 Noto Sans JP Black、Shippori Mincho SemiBold 字节、dataset、seed=42、配置、Renderer 和硬约束。B 的 20 条语义计划均来自实际兼容服务调用，服务报告模型 `gpt-6.1-sol`。

| 项目 | A 传统规则 | B 实时语义计划 |
|---|---|---|

API 时间与排版时间分别记录；本轮最后一次渲染复用了真实调用得到的计划，以相同的新配置重放，未重复计费 20 次。原始请求 ID、usage、调用延迟、语义计划、配置 hash、字体 hash 和全部候选见 `experiments/live-benchmark/results.json`。旧固定计划实验保留在 `experiments/benchmark`。

内部 Score 使用各方案自己的 importance，不能据均值宣布谁更好。A 能稳定生成大小层级与错位布局。B 在「待ちかねた再会」中选择的锚点更贴近参考，但其他样本没有一致优势。两套方案的视觉问题仍主要来自共用的几何规则与候选排名。

五条与细标重合的参考文本另行计算可见 ink 相对高度误差、行数差和强调位置 Jaccard，保留所有候选，不混成一个审美总分（`analysis/style_geometry.json`）。新候选池对部分样本更接近参考，首选结果却并非每条都改善。这些样本已用于开发，不是未见测试；新增七条只证明生成可用，不能证明风格等价。

Vision Critic 在三条标题上做了匿名 ID 排名实验：两条返回完整排名，分别首选 B 与 A 的候选；一条超时。成功调用约 35–36 秒，没有独立审美证据证明其收益，故保持关闭。详见 `experiments/vision_probe.json`。

界面将计划暂存在当前页面内存。字体、颜色、seed 和候选数改变时复用同一语义计划，避免重复请求；「重新规划」显式触发模型。A 无模型依赖；B 作为可选方案保留。没有预设 B 更好。
