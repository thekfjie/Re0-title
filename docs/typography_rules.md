# 可操作规则，非字体识别结果

规则先由 82 张截图的视觉证据提出，量化数据用于校验范围。`config/*.yaml` 集中保存可调参数；初始参数是实验起点，不冒充从逐字符标注精确拟合。

字号按 token 重要度与字符脚本共同分配。一个名词中仍允许单个汉字是主锚点。平假名有较小的默认字面，但不能把所有假名都设为低权重：#10「や」、#33「の」、#48「り」「ま」也可着色。混排字体通过 kanji/kana 角色选择，字形本身用实际 ink bbox 定位，不能用 CSS em 方框代替。

阅读顺序保持原始文本。形态素内部默认不拆；连续助词依附前词。标点与附属内容一起断行，禁行首标点、禁行末开括号、禁止标点独占行。输入过长时在安全字符边界拆分超长 token，但记录其惩罚。

断行使用 token 边界束搜索，同时考虑语义切口、行宽不均、模板预期行数。每个家族产生多种字号与偏移组合。阶梯家族按语义块横向交替，并非逐字符竖排；偏移以占用区域归一化。

颜色提供白色主体加少量强调，默认最多两个锚点、两个强调色。灰色属于可见层级。颜色选择可用于重复关系，不能只按 POS 决定。参考白底/纹理/倒影变体不自动推广为黑底生成规则。

间距使用字形 mask 的共同扫描行计算最小轮廓距离，允许 em 方框互相覆盖，但不能发生实际笔画严重碰撞。异字号、异字体配对每次测量，禁止固定全局 letter-spacing。标点缩小并下移，句尾允许小幅悬挂但仍必须在画布安全边界内。

整组先按真实路径界限缩放，再按面积加权墨迹质心居中。目标是保留周围留白，不是填满画布。各家族有不同目标 box fill。质量分数只描述已定义的约束和分布，不能等同于“好看”。

默认不旋转字符。参考 #81 的旋转与残缺纹理是特殊效果，不在本版常规母式中。模拟退火可改变行偏移、字块上下位置、字号、横向缩放及锚点色；原文、禁则和字体权限是硬约束。
