# 全部 82 张参考与 A 算法逐条对照

默认结果还没有稳定复用参考的视觉主线。它偏向单行，常把词首汉字当作强调锚点，难以区分语义重点、构图桥接与灰色弱化。多候选确实覆盖了更多合理断行，但现有评分经常没有把它们排到首位。这次保留全部 82 条标题与 492 张结果，不用少数成功案例代替结论。

在线入口：`/reference-comparison.html`。生成器的“参考标题 · 82”可搜索、按观察到的家族筛选并选用原文；白底样本自动选择白底画布。两个入口使用同一份目录。编号 069 有遮挡，保留 `■■なる晩餐会` 的可见转写，不猜隐藏文字。

## 本次怎么生成

使用 Python A：Sudachi → 规则角色 → 多家族/断行/尺度搜索 → 约束评分与退火 → 共用轮廓 Renderer。Noto Sans JP Black 与 Shippori Mincho SemiBold，1200 × 675，seed=42，每条 6 张，自动着色。全部参数与字体 hash 保存于 `experiments/reference-benchmark/results.json`，配置为 `config/reference_evaluation.yaml`。

生成只接收参考的文本与画布明暗，不接收该条参考的家族、断行、字号、色位、几何指标或图像。生成结束后才读取标注比较。本批样本此前参与过规则开发，因此这是开发样本的重建诊断，不是未见测试。此次没有调用 LLM，也没有把 A 结果标成 B。

原参考按同一视频画布裁切和缩放，标题的位置及留白保留；使用已校准的区域排除界面和中文字幕。页面可切换“原截图”核对裁剪。特殊背景可能仍有装饰或裁剪边缘，不把这类图纳入主要几何统计。

## 实际结果

内容可比 81 条，遮挡的 069 不计。普通黑底几何可比 59 条；其余 23 条仍展示。逐字符相对高度细标只有 6 条，不能声称已经拟合全体字号。

| 指标 | 默认第 1 张 | 六张候选的覆盖能力 |
|---|---:|---:|
| 行数一致 | 57 / 81 | 80 / 81 |
| 每个断点一致 | 56 / 81 | 74 / 81 |
| 人工家族标签一致 | 30 / 81 | 75 / 81 |
| 色位 Jaccard 的平均值 | 31.5% | 39.5% |

右列对每个指标分别寻找最接近参考的一张，不保证是同一候选，也不是用户默认获得的效果。家族命名本身是探索性人工归纳，只表示结构相似，不表示设计好坏。色位一致不等于色相、字号或节奏一致。

页面另提供“按参考筛选候选”：生成后依次比较断行、行数、色位与形状比例。该筛选的断行一致为 74/81，色位平均重合为 38.0%。它读取答案，专用于判断候选池与排名各有什么问题，不能当作算法性能提高。默认页面仍显示算法第 1 张，六张都可以手动查看和下载。

492 张均通过原文行拼接、可见 glyph 完整、禁则和画布边界检查；最大低分辨率 ink 重叠率为 0.002972。检查空白字符时不要求其有墨迹，这不代表拉丁词间空白的视觉处理已充分验证。排版引擎中位耗时 697 ms，不含字体初载、PNG 转换、网络或模型调用。这些是生成和约束检查，不是审美评分。

59 张的默认几何误差中位数：形状比例绝对对数误差 0.217；文字区域占比绝对差 9.18 个百分点；墨迹覆盖占比绝对差 3.59 个百分点；归一化画布质心距离 0.0248。6 张细标的默认字符相对高度平均绝对对数误差为 0.198。原字体身份未知，这些量不能直接归因于某个字体或解释为字号真值。

## 大小与留白：不能把所有结果统一放大

59 张的默认文字区域面积 / 参考面积中位数为 0.816，37 张默认更小。前 24 张中可靠黑底样本的中位比为 0.665，后续样本约为 1.010。早期标题常有巨大单字、强势字块，后续也有更紧凑的布局；单一平均填充目标会把它们混在一起。

应区分巨大单字主导、两侧锚点、中间桥接、错位多行等构图需求，再决定目标墨迹/区域覆盖和最大最小尺度比。不能直接提高所有标题的字号或填充参数。细标比较也显示：部分候选能改善相对高度，但默认选择仍不稳定。

## 着色：重要度不是原图颜色角色的充分解释

默认 47/81 条的强调位置与参考没有交集。它们通常已有颜色，只是落在不同字符上；这与“没有强调色”是不同问题。现有词性、汉字比例与词首优先规则过于粗糙。

逐图观察的具体差异：

- 002「再会の魔女」参考用巨大黄色“魔”主导；默认放大并着色“再”。问题同时涉及词内锚点、尺度及色相。
- 005「約束した朝は遠く」参考着色“束”，默认着色“約”；009「勇気の意味」参考强调“意”，默认强调“勇”；014「絶望という病」参考强调“病”，默认强调“絶”。名词词首不能充当通用规则。
- 010「鬼がかったやり方」参考着色假名“や”，默认选择“鬼”。只优先汉字会漏掉有构图作用的假名。
- 030「待ちかねた再会」参考蓝色“待”与粉色“再”形成两端关系；默认只有“再”的一个蓝色锚点。需要表达成对关系和强调预算，不能只取最高 importance。
- 033、035 的短结构让“の”担当彩色桥接。当前已有桥接例外，但默认乃至返回的候选仍可能没有这种构图。需要验证例外是否真正进入最终候选，而不是只验证函数能选中“の”。重复「的／の」也不能因此全部高亮。
- 048「聖域の始まりと、崩壊の始まり」四行虽然一致，参考的粉色分布和字号节奏仍未复用。匹配行数不能证明视觉主线一致。
- 051 的灰色“血／臓物”与白色“愛”，060 的灰色弱化与红色第二个“英”，079 的两段灰色文字，都包含弱化、重复对照或语气。单一“内容字 → 亮色”模型无法表达。
- 028「それぞれの誓い」的“誓”、076「棒振り」的“棒”等位置有匹配，但色相或相对尺度仍不同。位置匹配只是部分成功。

下一轮应把颜色角色拆为主锚点、关系锚点、构图桥接、弱化、整词和局部单字；语义重要度与视觉作用分别计算，再与布局一起选择。颜色数量、位置、灰度和色相分别评价，不把一个 Jaccard 分数当作好看。

## 比较依据与边界

- 断行：直接比较人工转写的每行字符串；行数一致另外记录。
- 色位：以 Unicode 字符出现位置建立集合，Jaccard = 交集 / 并集，重复字符不合并；两边都没有强调时为 1。参考包含灰色层级和近似颜色标注，生成以不同于前景色的 glyph 为强调。没有比较精确 RGB，也不能把高重合度当作色彩协调度。
- 几何：参考和生成均相对于整张标题画布测量。比较 ink bbox 宽高比、区域覆盖、ink 覆盖及像素质心；只对 59 张可靠黑底统计。
- 字面高度：字符 ink 高度 / 各自汉字中位 ink 高度，与 6 张细标比较。假名组的整体 bbox 不冒充逐字高度。
- 文字完整：核对行拼接及可见 glyph 转写；未知被遮挡文字不参与匹配结论。
- 发光、倒影、碎裂、纹理、渐隐等尚无对应 Renderer 处理。特殊样本保留展示，不能宣称复刻。
- Python 使用 Sudachi，在线浏览器使用 Kuromoji。冻结对照图由 Python 生成；在线选同一标题会重新生成，不承诺跨端逐像素相同。

本次范围是全部参考与 A 的比较；既有 20 条 A/B × 6 候选和实时语义计划保留，见 `comparison.md` 与 `/benchmark/`。没有补造 82 条 B 结果，也没有预设语义模型能解决共同的几何和排名问题。
