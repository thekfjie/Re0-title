# 82 个参考样本：证据与假设

来源是用户提供的 ZIP，包含 82 张 3200×1440 手机视频截图，未提供字体文件、矢量源文件或设计稿。全部已查看，编号按文件时间排序。`references/dataset.json` 保存逐样本文字、观察到的断行、脚本计数、形态素和布局类别；`analysis/measurements.json` 保存独立图像测量。原图只用于本地研究，不随公开站点传播。

## 先排除截图污染

左上 bilibili 标记、左下观看人数与中文翻译均不是日文标题。部分中文翻译在上方（#63、#73）、左侧（#17）或图中文字间（#80）；不能把简单全图阈值 bbox 作为标题 bbox。#25、29、31、60、65、69、70、77、82 是白底或浅底变体。#27 雪花、#31 花瓣、#43/53 渐变、#50 倒影、#54 血迹、#62 彩色背景不能参与普通黑底墨迹测量。#69 遮挡字保持未知。

## 重复出现的规律

1. 字形角色发生分化：汉字通常粗、直、密；假名常有明显书写曲线且更小。#2「再会の魔女」、#30「待ちかねた再会」、#48「聖域の…」支持混排假设，但无法仅凭截图确定字体名。
2. 单字是强调单位之一。#30 的「待」蓝、「再」粉，不是把整个「再会」同色处理。#33、35、38 的「の」着色，说明助词并非永远白色或不能强调。
3. 汉字也不等大：#2「魔」比「再会」「女」大；#12「王」大；#14「病」大。仅做“汉字大、假名小”不足以描述层级。
4. 基线、字面高度与字距都变化。假名嵌入大字周围，#8、#17、#48 的字间及行间关系明显不是固定 CSS 行高。
5. 多行保持阅读顺序，并有有限的几何母式。重复词会成为跨行对照锚点，例如 #24 的「騎士」、#60 的「最も…英雄」。
6. 黑底、白字与局部强调色是主要视觉方向。也存在灰字、纯色整块、低对比与白底例外；“关键词必着色”并不成立。
7. 装饰效果是额外层：#50 的倒影、#58/81 的纹理、#75 的发光，不能用字号参数复刻。第一版引擎不把它们当通用模板。

## 从样本归纳的家族

`compact_anchor`：极短标题，大字构成紧凑核心，#6、11、18、31、52、76。

`interwoven`：单行大内容字与较小连接部分交错，#2、5、9、14、30、35、59、74。横向锚点与混合字号在数据中高度重合，合为一个家族。

`wide_block`：连续内容字或纯片假名/拉丁字构成横块，局部层级，#19、22、41、54、57、62、63。

`offset_stack`：二至三行错位，组间有句法关系，#1、3、4、7、20、24、44、60、72、78。层级可发生在各行内部。

`alternating_steps`：窄而高，阅读块左右交替，#48 是最清楚的例证，#80 为复杂变体。仅两个样本支持，不能认定其参数分布已学稳。

这些是人工操作性分组，不是经聚类证实的“真实设计模板”。82 张来自同一系列，独立性与泛化范围有限，不进行小样本神经训练。`family_summary.json` 的类别数量是人工注释数量。

## 测量可靠性

像素层可测 foreground bbox、墨迹覆盖率、墨迹质心及颜色簇；由尺寸与颜色推字体、token 字号或真实轮廓缩放只能作假设。JPEG 抗锯齿、视频帧过渡、白字裁切和装饰会影响阈值。缺乏证据的 token bbox、字号比、字距保留 null，不用虚构数字填满表格。

逐字符精细标注仍是后续研究工作。第一版支持数据修订与参数再拟合，不能宣称已完成字体识别或达到设计师水平。

补充六张的 36 个字符/连续假名单元细标，含原图 bbox、观测 RGB、视觉角色与可审查误差（通常边缘 ±3 px，人工分界最高 ±12 px）。`fine_annotations.json` 严格使用 ink 高度比，font-size 与 font-family 留空。#30「ちかねた」合组，不冒充逐字符无误差轮廓。#48 的标点另计，避免缩小标点夸大正文层级比例。

前 24 张全部可靠黑底，标题框宽度中位占画布 0.855；后续可靠黑底样本为 0.656。墨迹留白中位分别 84.8% / 91.6%。因此候选使用多种尺度，不能把全部样本平均成唯一“字号规则”。
